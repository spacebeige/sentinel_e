PIPELINE FLOW:

    User Input (Native Script)
           ↓
    [1] Script Detection
           ↓
    [2] Phonetic Conversion (50-100ms)
    ├─ Character Mapping (native → phonetic)
    ├─ Multi-character sequence handling
    └─ Punctuation & symbol preservation
           ↓
    [3] TTS Provider Selection
    ├─ Sarvam (Primary for Indian languages)
    ├─ ElevenLabs (Multilingual fallback)
    ├─ Google Cloud (Free tier optional)
    ├─ Groq (Fast synthesis)
    └─ gTTS (Offline fallback)
           ↓
    [4] Audio Synthesis
    ├─ ritu voice (consistent, female)
    ├─ pace=1.0 (natural speed)
    └─ No post-processing (preserves quality)
           ↓
    [5] Audio Output
    ├─ WAV format (16-bit PCM, 16kHz)
    ├─ 7-9 seconds typical duration
    └─ Crystal-clear pronunciation

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROBLEM: Direct native script → TTS causes pronunciation errors

BEFORE (Without Phonetic):
  नमस्ते → [TTS] → "nm-s-t-e" [artifacts] ❌

AFTER (With Phonetic):
  नमस्ते → [Phonetic] → "namaste" → [TTS] → "nuh-muh-stey" ✅

KEY INSIGHT:
  Phonetic romanization creates a bridge between script and speech synthesis,
  allowing TTS engines (which are optimized for romanized text) to produce
  perfect pronunciation for any language script.

UNIVERSAL COMPATIBILITY:
  Works with ANY TTS provider because all providers handle romanized text well.
  The phonetic conversion "normalizes" all scripts to a common format that
  all TTS engines can process accurately.

BASIC USAGE:
  from awaaz.src.pipeline.tts import synthesize_speech
  result = synthesize_speech(text="नमस्ते", lang="hi", output_path="out.wav")

PHONETIC CONVERSION:
  from awaaz.src.pipeline.phonetic_converter import PhoneticConverter
  phonetic = PhoneticConverter.convert_to_phonetic("नमस्ते", "hi")

SUPPORTED LANGUAGES:
  hi, mr, ta, te, kn, ml, bn, gu, pa, or, as, en, si, kok, bho, mai, doi, awa, mwr, bgc

TTS PROVIDERS:
  sarvam (primary), elevenlabs (fallback), google_cloud (optional), groq (optional), gtts (fallback)

KEY FEATURES:
  ✅ Automatic phonetic conversion
  ✅ 20+ language support
  ✅ Zero voice breaking
  ✅ Mixed language support
  ✅ Multi-provider fallback
